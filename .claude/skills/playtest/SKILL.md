# 百鬼祓いを動かして確かめる

リアルタイムのアクションゲームなので、手で操作して終盤まで進めるのは現実的でない。
**テスト → ヘッドレスの通し走行 → ブラウザでデバッグ用フック**の順に、安いものから確かめる。

コマンドは必ずプロジェクトのルート（`.node-version` のあるフォルダ）で実行する（そこでないと nodenv が Node 22 に切り替わらない）。

## 1. テストと型

```bash
npm test
```

```bash
npm run typecheck
```

`src/core`（シミュレーション）はブラウザなしで検証できる。挙動を変えるときは、先にテストを失敗させてから直す。

## 2. ヘッドレスの通し走行（バランス）

```bash
npm run sim -- --char haruma --seeds 3
```

ボットが一夜を遊び、分ごとの「レベル・敵の数・撃破数・被ダメージ・与ダメージ」と、力尽きた時刻を出す。
`--god`（倒れない）で 20 分間の敵の量と成長の釣り合いを、`--shop` で社を最大にした場合を見られる。

目安：加護なしのボットで 6〜15 分、社を最大にすると夜明けに届く。祓い手 6 人（haruma・chihaya・goukai・kon・jubei・enku）で大きな差が出ていないかも見る。

## 3. ブラウザで確かめる

開発サーバーを起動する（`npm run dev`。ポート 5173）。

`http://localhost:5173/?debug=1` を開くと、プレイ開始後に `__hb` が使える（javascript_tool から呼ぶ）。

| 呼び出し | 効果 |
|---|---|
| `__hb.skip(秒)` | 経過時間を飛ばす（その時刻以降の出来事から再開） |
| `__hb.weapon(id, lv)` / `__hb.passive(id, lv)` | 装備を持たせる |
| `__hb.evolve()` | 条件を満たした武器を覚醒させる |
| `__hb.spawn(id, 数, 精鋭か)` | 妖怪を画面内に湧かせる |
| `__hb.xp(量)` / `__hb.chest()` | 経験値を与える／つづらを足元近くに置く |
| `__hb.auto(true)` | 自動操縦（選択肢もボットが選ぶ） |
| `__hb.god(true)` | 倒れない |
| `__hb.speed(n)` | n 倍速 |
| `__hb.advance(n)` | n tick 進めて 1 回描く（タブが裏でも動く。処理時間の計測にも使える） |
| `__hb.world` | シミュレーションの状態そのもの |

音は耳で確かめられないので、`await __renderOffline({ music: 'stage', intensity: 3 }, 12)` や `{ sfx: 'hit' }` でピークと RMS を数値で見る（無音でない・クリップしていない）。

### 場面の出し方

| 見たいもの | やり方 |
|---|---|
| レベルアップ画面 | `__hb.xp(5)` |
| つづら・覚醒 | 武器を Lv8、対応する装身具を持たせて `__hb.chest()` → つづらの上へ移動 |
| 大妖 | `__hb.skip(297)`／`597`／`897`／`1137` の数秒後 |
| 塗り壁の包囲／輪入道／百鬼夜行 | `__hb.skip(417)`／`507`／`779` |
| 夜明け → 結果 | `__hb.god(true)` のうえ `__hb.skip(1196)` |
| 力尽きる → 結果 | `__hb.god(false)` で体力を 1 にして `__hb.spawn('oni_red', 30)` |

### 気をつけること

- **検証で進めたセーブは消す**：結果画面まで進めると小判や祓い手の解放が localStorage に残る。終わったら `localStorage.removeItem('hyakki-barai.save')` を実行する
- キー入力を自動で続けて送ると、1/60 秒の間に届いた操作が同じ tick で処理される。メニューの移動と値の変更を続けて送るときは、間に待ちを入れる
- 画面は論理解像度で高さ 360px 固定・幅 480〜800px。ウィンドウの縦横比を変えて、狭い幅（480）でも UI が収まるかを見る
