# 百鬼祓いのドット絵を描く・直す

このプロジェクトのドット絵は画像ファイルではなく、`src/art/sprites/*.ts` にパレット記号のグリッドとして書く。
描いたら必ず PNG に書き出し、Read で開いて目で確認する（文字のグリッドを眺めても仕上がりは分からない）。

## 手順

1. **契約を確認する**：`src/art/manifest.ts` に、ゲームが必要とする ID・サイズ・最小フレーム数が並んでいる。新しい絵が必要なら、まずここに 1 行足す（足した時点で `manifest.test.ts` が失敗する＝Red）。
2. **描く**：該当するファイル（`enemies.ts`・`bosses.ts`・`characters.ts`・`icons.ts`・`items.ts`・`projectiles.ts`・`decor.ts`・`ui.ts`）に `sprite(id, w, h, [フレーム…], opts)` で定義する。
   - 記号は `src/art/palette.ts` にあるものだけ。`.` は透明
   - 既定の原点は足元（下端中央）。アイコンや弾は `{ anchor: 'center' }`
   - 2 コマ目は `bob()`（上を 1px 沈める）と `patch()`（指定行を差し替える）で作れる。色違いは `recolor()`
   - 大きく単純な形（鳥居・木など）は `src/art/paint.ts` の `paint()` で図形を重ねて作る
3. **テストを通す**：`npx vitest run src/art`（サイズ・フレーム数・記号・ID の重複を検証する）
4. **目で確認する**：
   ```bash
   npm run sprites -- --match '^enemy\.' --out <スクラッチパッド>/sheet.png --scale 5 --glow
   ```
   出力された PNG を Read で開く。各スプライトは大きな表示の右隣に、ゲーム内の見え方に近い 2 倍表示が並ぶ。`--glow` を付けると発光マスクの行が増える。
5. 形が崩れている・見分けにくい・地味なものを描き直し、4 に戻る。

## スタイルの決まり

- 斜め見下ろし・右向きに描く（左向きは描画側が自動で反転する）
- 輪郭は記号 `0`（墨色）で 1px。光・炎・霊体だけは黒輪郭ではなく、同系色の暗い縁取りにする
- 1 素材につき 2〜3 階調。光源は左上
- ゲーム内では 2 倍表示で数百体が同時に出る。**種類ごとに主色とシルエットを変え、一瞬で見分けられること**が最優先。地面は暗い藍〜緑なので、暗色だけの絵は埋もれる
- 闇の中で光らせたい部分（目・炎）は `glow` に記号を指定する。指定した記号はそのスプライト内の全ピクセルが光るので、光らせたくない場所に同じ記号を使わない

## 使う側とのつながり

- 妖怪は `enemy.<EnemyId>`、大妖は `boss.<EnemyId>`、祓い手は `char.<CharacterId>`、アイコンは `icon.w.<WeaponId>`／`icon.p.<PassiveId>` という ID で描画側（`src/render/worldView.ts`・`src/ui/`）から参照される
- 祓い手はフレーム 0 が立ち姿で、歩行中は全フレームを順に繰り返す
- 向きのある弾は右向きに描く（描画時に回転される）
