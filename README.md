# 百鬼祓い（HYAKKI-BARAI）

逢魔が時から夜明けまでの 20 分間、押し寄せる百鬼夜行を祓い続ける、和風のサバイバーズライク（ブラウザゲーム）。

操作するのは移動だけ。武器はひとりでに妖怪を祓い、落とした霊玉を集めてレベルが上がるたびに、御札を 1 枚選んで強くなっていく。

- ドット絵はすべてコードで定義した自作（画像ファイルなし）、音は Web Audio の合成のみ
- 外部素材はフォント [DotGothic16](https://fonts.google.com/specimen/DotGothic16)（SIL Open Font License 1.1）だけ

## 遊び方

```bash
npm install
npm run dev
```

`http://localhost:5173` を開く。Node は 22 系を使う（nodenv なら `.node-version` で自動的に切り替わる）。

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 移動・メニューの選択 | WASD／矢印キー | 左スティック／十字キー |
| 決定 | Enter／Space／Z | A |
| 一時停止・もどる | Esc／P | Start／B |
| 選択肢を直接選ぶ | 1〜4 | — |
| 振り直し／見送り | R／X | X／Y |

マウスやタッチでも操作できる（タッチは画面を押した位置が仮想スティックになる）。

## ゲームの流れ

1. **祓い手を選ぶ**：最初は陰陽師の晴真と巫女の千早。残り 4 人は条件を満たすと加わる
2. **一夜を生き延びる**：妖怪を祓って霊玉を集め、レベルアップのたびに武器か装身具を選ぶ（武器 6 枠・装身具 6 枠）
3. **つづらで覚醒**：武器を最大レベルにして対応する装身具を持ち、精鋭や大妖が落とすつづらを開けると、武器が覚醒する
4. **社で加護を授かる**：持ち帰った小判で、次の夜から効く永続の強化を買う

夜は 5 分ごとに大妖が現れ（金棒鬼 → 土蜘蛛 → がしゃどくろ → 酒呑童子）、20:00 に朝日が差せば勝ち。

## 開発

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー |
| `npm test` | テスト（Vitest） |
| `npm run typecheck` | 型チェック |
| `npm run build` | 型チェックのうえ `dist/` に本番ビルド（静的ファイルとしてどこにでも置ける） |
| `npm run sim` | ボットに一夜を通しで遊ばせ、分ごとの敵の数・撃破数・レベルなどを表示（バランス調整用） |
| `npm run sprites` | スプライト一覧を PNG に書き出す（ドット絵の確認用） |

`npm run sim` は `--char <id>`（祓い手）、`--seeds <n>`（試行回数）、`--god`（倒れない）、`--shop`（社を最大）を受けつける。
`npm run sprites` は `--match <正規表現>`、`--out <パス>`、`--scale <倍率>`、`--glow`（発光部分も表示）を受けつける。

### 構成

依存の向きは外側から内側へ。`core` は DOM にも他の層にも依存しない。

```
src/
  core/    シミュレーション本体（固定 60Hz・シード付き乱数で決定的に動く）
    data/    武器・装身具・妖怪・祓い手・進行表・社の定義
    sim/     World と各システム（移動・武器・弾・敵の行動・出現・落とし物・選択肢・大妖）
    meta/    セーブ・社・祓い手の解放
    bot/     自動操縦（バランス検証とデモ用）
  art/     パレットとスプライト定義（記号のグリッドで書いたドット絵）
  render/  アトラス生成・地面・夜の灯り・パーティクル・文字
  audio/   効果音と BGM のシンセ（AudioPort の実装）
  input/   キーボード・ゲームパッド・ポインタ
  ui/      HUD と各画面の部品
  infra/   localStorage
  app/     ゲームループとシーン（ここで各層をつなぐ）
scripts/   スプライト一覧の出力、バランス検証
```

シミュレーションは音も画面も知らず、毎 tick の出来事（`SimEvent`）を出すだけ。音・パーティクル・画面揺れ・告知は、外側がそれを読んで鳴らす／描く。
だから `core` はブラウザなしでテストでき、20 分の一夜をヘッドレスで数秒で回せる。

### デバッグ

URL に `?debug=1` を付けると、コンソールから `__hb` で状態を操作できる。

```js
__hb.skip(590)          // 経過時間を 9:50 に飛ばす
__hb.weapon('juzu', 8)  // 武器を持たせる（レベル指定）
__hb.passive('senko', 1)
__hb.evolve()           // 条件を満たした武器を覚醒させる
__hb.spawn('oni_red', 50)
__hb.auto(true)         // 自動操縦
__hb.god(true)          // 倒れない
__hb.speed(4)           // 4 倍速
```

`?mute` を付けると無音で起動する。
